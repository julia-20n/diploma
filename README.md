# Компресійний та статистичний аналіз замаскованих послідовностей

Цей репозиторій містить вихідний код експериментальної частини кваліфікаційної роботи. Програма призначена для моделювання прихованих структурних залежностей у потоках даних та порівняння чутливості різних методів аналізу до їх виявлення.

## Опис експерименту та аналізу

Код виконує серію з 30 ітерацій комп'ютерного моделювання, кожна з яких включає наступні етапи:

1. **Моделювання даних:** Генерація еталонного випадкового шуму (`os.urandom`) та модифікованої послідовності. У модифікованих даних 2 молодші біти (LSB) піддаються детермінованому нелінійному перетворенню (S-box), а 6 старших бітів залишаються випадковими (ентропійне маскування).
2. **Статистичний аналіз:** Перевірка згенерованих потоків за допомогою батареї тестів NIST SP 800-22 (через пакет `nistrng`). Аналізується як повна 8-бітна послідовність, так і ізольована 2-бітна LSB-проєкція.
3. **Компресійний аналіз:** Стиснення даних за допомогою словникового алгоритму LZMA та контекстно-орієнтованого предиктивного алгоритму ZPAQ з розрахунком нормалізованих коефіцієнтів стиснення.
4. **Статистична оцінка:** Розрахунок критерію Вілкоксона для зв'язаних вибірок, щоб підтвердити статистичну значущість здатності алгоритму ZPAQ виявляти вбудовану структурну надмірність. Побудова підсумкових графіків.

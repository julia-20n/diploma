# Компресійний та статистичний аналіз замаскованих послідовностей

Цей репозиторій містить вихідний код експериментальної частини кваліфікаційної роботи. Програма призначена для моделювання прихованих структурних залежностей у потоках даних та порівняння чутливості різних методів аналізу до їх виявлення.
